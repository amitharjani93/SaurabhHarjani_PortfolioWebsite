Place the professional portrait in this folder.

  1. Save the file here as `portrait.jpg` (or `.webp`). A 4:5 crop at roughly
     1200 × 1500 px is ideal — it is displayed at up to 640 px wide.
  2. Open `src/config/site.ts` and set:

       portrait: '/profile/portrait.jpg',

  3. Adjust `portraitAlt` in the same block if a different description is wanted.

Until a photograph is supplied, the profile page renders a typographic panel in
its place. No stock photograph or AI-generated likeness is used.
